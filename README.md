# AIA

The acronym of this repository stands for **AI**-**A**ssisted (or _**A**idé par l'**IA**_). 
It is meant to collect research articles which have been produced with the help of a generative artificial intelligence chatbot,
initially ChatGPT, which I started using on 10/13/2026.
Due to their peculiar nature, these articles may not find their way in standard mathematical journals.
